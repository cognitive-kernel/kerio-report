# Kerio Report

سامانه گزارش‌گیری فارسی و راست‌چین برای Kerio Control با PHP 8.2، Apache و MySQL.

## صفحات گزارش
- داشبورد کلی: آمار دستگاه‌ها، فعالیت امروز، نمودار ترافیک هفت روز اخیر و آخرین رویدادها.
- گزارش بازه زمانی: انتخاب تاریخ شروع و پایان، ترافیک روزانه و خلاصه اتصالات.
- گزارش سیستم‌ها: خلاصه فعالیت، تعداد اتصال و درخواست وب و ترافیک ثبت‌شده برای هر دستگاه.
- وضعیت لحظه‌ای: آخرین وضعیت ذخیره‌شده دستگاه‌ها با تازه‌سازی ۳۰ ثانیه‌ای.
- اتصالات شبکه: فهرست اتصال‌ها با فیلتر بازه زمانی.
- وب‌سایت‌ها: تعداد درخواست‌ها و URLهای ثبت‌شده با فیلتر بازه زمانی.\n- لینک‌های هر سیستم: فیلتر دستگاه و بازه زمانی، خلاصه تعداد لینک‌ها و فهرست URLها با نام سیستم و IP.

## نصب روی XAMPP
1. مخزن را در پوشه‌ای مانند `C:\\xampp\\htdocs\\kerio_report` قرار دهید.
2. دیتابیس را با اجرای `database/schema.sql` ایجاد کنید.
3. فایل `config.example.php` را به `config.local.php` کپی و مشخصات محلی MySQL و Kerio را تکمیل کنید.
4. Apache و MySQL را اجرا کنید.
5. آدرس `http://localhost:8080/kerio_report/public/` را باز کنید.

## بهینه‌سازی دیتابیس موجود
- برای سرعت گزارش «۱۰ مصرف‌کننده برتر در بازه انتخابی»، ایندکس ترکیبی با ترتیب `(occurred_at, device_id, bytes_total)` برای فیلتر بازه زمانی استفاده می‌شود. در نصب جدید این ایندکس از `database/schema.sql` ساخته می‌شود.
- پس از دریافت این نسخه روی دیتابیس موجود، فایل `database/migrations/20261103_connection_time_device_index.sql` را یک‌بار از تب SQL در phpMyAdmin اجرا کنید. این migration را فقط یک‌بار اجرا کنید؛ اجرای مجدد آن به‌دلیل نام تکراری ایندکس خطا می‌دهد.

## نکات مهم
- صفحات گزارش فقط داده‌های موجود در دیتابیس را نمایش می‌دهند؛ تا زمان تکمیل و اجرای Collector ممکن است گزارش‌ها خالی باشند.
- صفحه لحظه‌ای آخرین نمونه ذخیره‌شده را نشان می‌دهد و جایگزین polling مستقیم Kerio نیست.
- اجرای اولیه Collector از خط فرمان: `C:\\xampp\\php\\php.exe C:\\xampp\\htdocs\\kerio_report\\bin\\collect.php`؛ اطلاعات اتصال Kerio باید در بخش `kerio` فایل `config.local.php` تنظیم شده باشد.
- همگام‌سازی لاگ‌های Connection و HTTP: `C:\\xampp\\php\\php.exe C:\\xampp\\htdocs\\kerio_report\\bin\\sync-logs.php`. این فرمان هر بار تا ۲۰ بسته ۵۰۰۰ خطی را پردازش می‌کند؛ اگر لاگ بزرگ‌تر باشد، اجرای بعدی از cursor ذخیره‌شده ادامه می‌دهد.\n- اجرای `bin\\collect.php` برای به‌روزرسانی فهرست دستگاه‌های فعال و اجرای `bin\\sync-logs.php` برای ذخیره لاگ‌ها را در Windows Task Scheduler به‌صورت دوره‌ای زمان‌بندی کنید.\n- cursor هر نوع لاگ جداگانه در `sync_state` ذخیره می‌شود. درج‌ها با کلید یکتای SHA-256 و `INSERT IGNORE` در برابر اجرای مجدد محافظت می‌شوند. در صورت بروز خطا، cursor همان بسته commit نمی‌شود و بسته در اجرای بعدی دوباره خوانده خواهد شد.\n- درخواست‌های HTTP به مسیر مدیریتی `/admin/` از گزارش وب حذف می‌شوند. لاگ HTTP فقط درخواست‌های قابل مشاهده از طریق HTTP inspection/proxy را پوشش می‌دهد؛ URL کامل HTTPS معمولاً در دسترس نیست.\n- مقدار اول `[Bytes]` در لاگ Connection به‌عنوان ارسال و مقدار دوم به‌عنوان دریافت ذخیره می‌شود؛ مقدار سوم جمع کل است.
- افزونه PHP cURL باید در XAMPP فعال باشد. اعتبارسنجی TLS طبق تنظیم `verify_tls` انجام می‌شود و به‌صورت پیش‌فرض فعال است.
- حجم ترافیک نمونه‌ها با واحد KB در schema نگهداری می‌شود؛ صحت تفکیک upload/download باید در Collector بر اساس رفتار واقعی API کنترل شود.
- لاگ HTTP می‌تواند URL درخواست‌های قابل مشاهده را ثبت کند؛ مسیر کامل صفحات HTTPS معمولاً از لاگ عادی قابل استخراج نیست.
- فایل `config.local.php` شامل رمزهاست و نباید به Git ارسال شود.
- Chart.js و فونت Vazirmatn از CDN بارگیری می‌شوند و برای نمایش نمودار و فونت به دسترسی اینترنت مرورگر نیاز است.
